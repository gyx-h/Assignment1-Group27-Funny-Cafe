# Assignment1-Group27-Funny-Cafe
Group 27 Web Design Assignment-Funny Cafe Static Website

## Project Overview
This is a student group assignment for Web Design course.
We developed a static website prototype for Funny Cafe,a local coffee shop.

### Website Pages
- index.html:Homepage
- menu.html:Food & Drink Menu
- photo.html:Photo Gallery
- reserve.html:Table Reservation Page

### Project Structure
- css/:CSS stylesheets
- js/:JavaScript interactive scripts
- images/:Food and café picture assets

### Technology Stack
HTML5,CSS3,Vanilla JavaScript
